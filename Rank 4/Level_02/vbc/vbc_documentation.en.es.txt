VBC - Compilador muy básico
Descripción general
VBC (Very Basic Compiler) es un analizador y evaluador de expresiones matemáticas que implementa un analizador de descenso recursivo para construir un Árbol de Sintaxis Abstracta (AST). El compilador maneja operaciones aritméticas básicas con la precedencia de operadores adecuada y agrupación entre paréntesis.
Operaciones apoyadas
- Adición (+)
- Multiplicación (*)
- Agrupación entre paréntesis (())
Restricciones de entrada
- Operandos: Dígitos individuales (0-9)
- Longitud de la expresión: Variable
- Sintaxis: Notación matemática infija estándar
Conceptos básicos
Asociatividad izquierda
La asociatividad por la izquierda define el orden de evaluación para operadores de igual precedencia, garantizando la corrección matemática en el análisis de expresiones.
Ejemplo: 1 + 2 + 3 se analiza como ((1 + 2) + 3)
Este concepto influye directamente en la construcción del AST, donde cada nuevo nodo operador adopta el subárbol construido previamente como su hijo izquierdo.
Algoritmo de construcción de AST
El analizador sintáctico construye el AST de forma incremental utilizando un enfoque ascendente:
Paso 1: Operación binaria inicial
Expresión: 1 + 2
AST:
      +
     / \
    1 2
Paso 2: Extensión de la cadena
Expresión: 1 + 2 + 3
AST:
        +
       / \
      + 3
     / \
    1 2
El algoritmo garantiza que:
1. Cada nuevo nodo operador se convierte en la raíz
2. El AST anterior se convierte en el subárbol izquierdo.
3. El nuevo operando se convierte en el hijo derecho
4. Se conserva la asociatividad por la izquierda.
Estructuras de datos
Estructura de nodos
typedef struct nodo {
    enumeración {
        ADD, // Nodo del operador de suma
        MULTI, // Nodo del operador de multiplicación  
        VAL // Nodo hoja de valor
    } tipo;
    int val; // Valor del nodo (para nodos VAL)
    struct node *l; // Puntero al hijo izquierdo
    struct node *r; // Puntero al hijo derecho
} nodo;
Descripción de los campos:
- tipo: Enumeración de discriminador que define la operación del nodo o el tipo de valor
- val: Almacenamiento de valores enteros (utilizado únicamente para nodos de tipo VAL)
- l: Puntero al nodo hijo izquierdo
- r: Puntero al nodo hijo derecho
Gestión de la memoria
vacío destruir_árbol(nodo *n)
{
    si (!n)
        devolver;
    si (n->tipo != VAL)
    {
        destruir_árbol(n->l);
        destruir_árbol(n->r);
    }
    libre(n);
}
Algoritmo:
1. Caso base: Devolver si el nodo es NULL
2. Caso recursivo: Para nodos que no son hojas, destruir recursivamente los hijos
3. Limpieza: Liberar la memoria del nodo actual
La función aprovecha el hecho de que los nodos VAL siempre son hojas (no tienen hijos que destruir).
Arquitectura del analizador sintáctico
Punto de entrada: parse_addition(char *s)
La función de análisis principal que inicia el proceso de análisis recursivo y se encarga de:
- Validación de expresiones
- Gestión de precedencia del operador
- Agrupación entre paréntesis
- Detección y notificación de errores
Estrategia de análisis sintáctico
El analizador sintáctico implementa un enfoque de descenso recursivo por capas:
Capa 1: Validación de la expresión primaria
- Literal numérico: Crea un nodo VAL (hoja)
- Expresión entre paréntesis: Llama recursivamente a parse_addition() para la subexpresión
Capa 2: Manejo de la multiplicación
- Continúa el procesamiento dentro del nivel de precedencia actual
- Genera el nodo operando derecho para las operaciones de multiplicación
Capa 3: Procesamiento de suma
- Regresa a parse_addition() para operaciones de menor precedencia
- Crea un nodo adicional con el AST anterior como hijo izquierdo
- Valida los tokens subsiguientes para continuar el análisis

Glosario técnico
Término
Definición
AST
Árbol de sintaxis abstracta: representación jerárquica de la estructura de una expresión.
Asociativo a la izquierda
Orden de evaluación donde los operadores de igual precedencia se procesan de izquierda a derecha
Descenso recursivo
Técnica de análisis sintáctico descendente mediante llamadas a funciones recursivas
Expresión primaria
Unidad de expresión atómica (número o grupo entre paréntesis)
Nivel de precedencia
La prioridad del operador determina el orden de evaluación
Flujo de trabajo de implementación
Expresión de entrada → Análisis léxico → Análisis sintáctico → Construcción del AST → Evaluación
                ↓ ↓ ↓ ↓
            Flujo de tokens → Árbol de análisis → Árbol abstracto → Valor de resultado
Fases de análisis
1. Análisis sintáctico primario: Identificar los elementos básicos (números, paréntesis)
2. Capa de multiplicación: Gestiona operaciones de alta precedencia
3. Capa de adición: Procesar operaciones de baja precedencia
4. Ensamblaje del árbol: Construir el AST final con la asociatividad adecuada.
5. Validación: Asegurar la corrección sintáctica
El enfoque multicapa garantiza la correcta precedencia de los operadores al tiempo que mantiene la modularidad del código y el aislamiento de errores.
