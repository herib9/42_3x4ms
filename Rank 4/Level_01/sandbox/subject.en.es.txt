Nombre de la tarea: 	sandbox
Archivos esperados: 	sandbox.c
Funciones permitidas:	fork, waitpid, exit, alarm, sigaction, kill, printf, strsignal,
						errno, sigaddset, sigemptyset, sigfillset, sigdelset, sigismember
--------------------------------------------------------------------------------------

Escribe la siguiente función:

#include <stdbool.h>
int sandbox(void (*f)(void), unsigned int timeout, bool verbose);

Esta función debe comprobar si la función f es una función buena o mala.
Devolverá 1 si f es buena, 0 si f es mala o -1 en caso de error en su función.

Una función se considera defectuosa si se termina o se detiene por una señal (fallo de segmentación, aborto...).
si finaliza con cualquier código de salida distinto de 0 o si se agota el tiempo de espera.

Si el modo detallado está activado, debe escribir el mensaje apropiado entre los siguientes:
"Nice function!\n"
"Bad function: exited with code <exit_code>\n"
"Bad function: <signal description>\n"
"Bad function: timed out after <timeout> seconds\n"

No debes tener fugas de procesos (ni siquiera en estado zombie, esto se comprobará mediante wait).

Probaremos tu código con funciones muy malas.
